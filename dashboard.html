Buat Link Gallery Pemilihan Foto Klien

Masukkan nama klien, link Google Drive, dan batas jumlah foto. Sistem akan membuat link khusus yang bisa langsung diakses klien dari HP mana saja.

Nama ini akan muncul sebagai judul sambutan di halaman gallery klien.

Set ke "Anyone with link can view"
Preset:

Klien tidak akan bisa memilih lebih dari jumlah ini (muncul peringatan ramah otomatis).

Setelah klien selesai memilih foto, mereka bisa 1-klik mengirim daftar kode foto langsung ke nomor WA ini.

Bagaimana Cara Kerjanya?

  • 1
    Upload Foto ke Google Drive Buat folder di Google Drive, upload foto hasil jepretan, lalu set share link ke "Anyone with the link can view".
  • 2
    Buat Link Gallery Paste link folder Google Drive di form ini, atur batas foto (misal 20), lalu klik buat project.
  • 3
    Kirim Link ke Klien Kirim link ke WhatsApp klien. Klien bisa buka di HP dari mana saja, preview foto full-screen, dan pilih hingga batas kuota.
  • 4
    Terima Rekap di WhatsApp Setelah selesai, klien klik "Kirim ke WhatsApp". Anda akan menerima daftar kode foto lengkap & format filter Lightroom!

Pengaturan Google Drive API Key

Diperlukan agar web app bisa membaca file foto dari Google Drive tanpa login.

API Key tersimpan aman di browser Anda dan otomatis disisipkan ke link gallery klien.

Cara Dapatkan API Key Gratis (2 Menit):

  1. Buka Google Cloud Console (gratis).
  2. Buat project baru (misal: Inhistoria Gallery).
  3. Buka menu APIs & Services → cari Google Drive API → klik Enable.
  4. Buka menu Credentials → klik Create Credentials → pilih API Key.
  5. Copy API Key yang muncul lalu paste di kotak di atas. Selesai!
